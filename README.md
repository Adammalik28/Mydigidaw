# Mydigidaw

[![Unduh APK](https://img.shields.io/badge/Download-APK%20v2.2-2ea44f?style=for-the-badge&logo=android&logoColor=white)](https://github.com/Adammalik28/Mydigidaw/releases/latest)

Aplikasi Android produktivitas all-in-one yang dibangun menggunakan **Jetpack Compose** dan **Kotlin**.

## 📥 Unduh Aplikasi (APK)
Anda dapat mengunduh file APK siap pasang langsung melalui tab [**Releases**](https://github.com/Adammalik28/Mydigidaw/releases/latest) atau klik tombol unduh di atas.

## ✨ Fitur Utama

- **Tugas & Kebiasaan (Tasks & Habits)**: Pengingat cerdas, pelacakan rutinitas, dan checklist tugas.
- **Catatan & Ide (Notes)**: Pencatatan cepat, integrasi checklist, dan pengorganisasian catatan.
- **Keuangan (Finance)**: Pencatatan transaksi, kalkulasi keuangan, dan visualisasi grafik.
- **Kalender & Jadwal (Calendar)**: Sinkronisasi dengan Google Calendar perangkat dan pengingat alarm tepat waktu.
- **Vault Terenkripsi**: Penyimpanan data sensitif dengan enkripsi biometrik / keamanan tingkat perangkat.
- **Widget Layar Utama**: Widget ringkasan untuk akses cepat informasi harian langsung dari launcher.
- **Integrasi Menu Berbagi (Quick Share)**: Simpan teks langsung ke Mydigidaw dari aplikasi lain.

## 🛠️ Teknologi yang Digunakan

- **Bahasa**: Kotlin
- **UI Framework**: Jetpack Compose (Material 3)
- **Arsitektur**: Clean Architecture / MVVM
- **Database**: Room Database
- **Background Work**: WorkManager & Exact Alarms
- **Build System**: Gradle dengan Kotlin DSL (`build.gradle.kts`)

## 🚀 Memulai (Build & Run)

1. Clone repositori ini:
   ```bash
   git clone https://github.com/Adammalik28/Mydigidaw.git
   ```
2. Buka proyek di Android Studio (Ladybug atau yang lebih baru direkomendasikan).
3. Sinkronkan Gradle (`Sync Project with Gradle Files`).
4. Jalankan pada emulator atau perangkat fisik Android (Min SDK: Android 8.0 Oreo / API 26).
